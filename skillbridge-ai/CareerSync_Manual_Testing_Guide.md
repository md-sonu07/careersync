## 🧪 3. Step-by-Step Manual Test Execution Scenarios

---

### Scenario A: Student User Journey (Skill Assessment → Gap Engine → Matching → Application)

#### Step A1: Authentication & Login
1. Open [`http://localhost:5173/login`](http://localhost:5173/login).
2. Enter Email: `student@skillbridge.ai` and Password: `Password123!`.
3. Click **Login**.
4. **Expected Result**: Successfully redirects to Student Dashboard ([`http://localhost:5173/student/dashboard`](http://localhost:5173/student/dashboard)). JWT tokens stored in localStorage.

#### Step A2: View Skill Progress & Levels (Phase 5)
1. Navigate to **My Skills** ([`http://localhost:5173/student/skills`](http://localhost:5173/student/skills)).
2. Observe your current scores and automatically calculated level badges (*Beginner*, *Intermediate*, *Advanced*, *Expert*).
3. **Expected Result**: Skill scores and verification badges (*Verified ✓*) display correctly from Django backend.

#### Step A3: Take Skill Assessment & Score Auto-Calculation (Phase 6 & 7)
1. Navigate to **Assessments / Quizzes** ([`http://localhost:5173/student/assessments`](http://localhost:5173/student/assessments)).
2. Choose **Python Foundations Assessment** and click **Start Assessment**.
3. Answer the MCQ questions in the modal interface and click **Submit Quiz**.
4. **Expected Result**:
   - Backend calculates score & accuracy percentage.
   - `StudentSkill` record is updated with new score, `last_assessed_at` timestamp, and verified status if score >= 60%.
   - `SkillScoreHistory` entry is logged.

#### Step A4: Skill Gap Engine Analysis (Phase 8)
1. Navigate to **Skill Gap Analysis** ([`http://localhost:5173/student/skill-gap`](http://localhost:5173/student/skill-gap)).
2. Observe current skill scores vs target career role (*Full Stack Developer*) benchmarks.
3. Observe severity classifications (*High*, *Medium*, *Low*).
4. Click **Recalculate Gaps ↻**.
5. **Expected Result**: Gaps recalculate instantly using formula max(Required - Current, 0) with live API response.

#### Step A5: Gap-Driven Learning Recommendations (Phase 9)
1. Navigate to **My Learning** ([`http://localhost:5173/student/my-learning`](http://localhost:5173/student/my-learning)).
2. Review **Personalized Gap Recommendations** generated by Phase 9 Engine.
3. Observe custom reason badges (e.g. *"Recommended because Python has a 90% gap against target benchmark"*).
4. Click **Mark Done ✓** on a recommendation module.
5. **Expected Result**: Recommendation status updates from `pending` / `in_progress` to `completed` in backend DB.

#### Step A6: Opportunity Matching & Applying to Internships (Phase 10, 11 & 12)
1. Navigate to **Internships** ([`http://localhost:5173/student/internships`](http://localhost:5173/student/internships)).
2. Observe live postings (*Flipkart*, *CRED*, *Postman*) with required skill benchmarks.
3. Click **Apply Now** on *Frontend Engineering Intern @ Flipkart*.
4. **Expected Result**:
   - Application is created in database with initial status `applied`.
   - Button label updates to **"Applied ✓"**.
   - Attempting to click apply again handles duplicate prevention with friendly alert (*"Already applied"*).

#### Step A7: Pipeline Stepper & Application Audit History (Phase 12)
1. Navigate to **My Applications** ([`http://localhost:5173/student/applications`](http://localhost:5173/student/applications)).
2. Observe pipeline stepper progress (*Applied* -> *Under Review* -> *Shortlisted* -> *Interview* -> *Selected*).
3. **Expected Result**: Status and applied timestamp display live data from backend.

#### Step A8: Learning & Career Analytics (Phase 13)
1. Navigate to **Analytics** ([`http://localhost:5173/student/analytics`](http://localhost:5173/student/analytics)).
2. Review Career Readiness Score %, Verified Skills count, Assessment Pass Rate %, and Active Skill Gaps.
3. **Expected Result**: Dynamic ORM query analytics load cleanly with zero hardcoded values.

## 🛠 4. Testing APIs via Swagger Interactive Documentation

1. Open [`http://127.0.0.1:8000/swagger/`](http://127.0.0.1:8000/swagger/) in browser.
2. Click **Authorize** (top right) and enter your JWT access token:
   ```text
   Bearer <your_jwt_access_token>
   ```
3. Expand endpoints to test:
   - `POST /api/auth/login/` -> Obtain fresh tokens.
   - `GET /api/skills/gaps/` -> View skill gaps.
   - `GET /api/courses/recommendations/` -> View learning recommendations.
   - `GET /api/opportunities/matches/` -> View AI weighted opportunity matches.
   - `GET /api/applications/my/` -> View submitted applications.
   - `GET /api/analytics/student/` -> View dynamic student analytics.
